# 瞬拍

限時競投拍賣場。唔使登入都可以睇拍賣列表；登入後先可以刊登同叫價。

## 功能

- 物品最多 3 張圖、名稱、可選描述（支援換行）
- 拍賣時限 2 小時或 8 小時
- 列表由最新開始；拍賣中 view 最高 5 件有人氣 No.1–5
- 物品頁：物品 → 出價 → 網站連結（紅色掣，預設 Carousell，外部連結提示）→ 分享
- 可加 YouTube
- 賣家睇 view count；流標可重新拍賣
- 物品 7 日後刪除
- 管理員可下架拍賣或封鎖／解封用戶

## 本機運行

```bash
npm install
npm run dev
```

需要 Postgres（或用內建 PGLite 後備）。登入支援 Google、X、電郵密碼。
